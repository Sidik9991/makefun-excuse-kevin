# The Excuse Your Agent Gives You

Entry for the make.fun bounty [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261): one line, at most 200 characters — the single funniest excuse an AI agent hands its human after shipping a bug.

`main.ts` (Node 22, no dependencies) scores 13 fresh candidate lines against the judge's five criteria (one-line excuse gate, laugh on first read, absurdity of an agent owning its code, sharp turn at the end, agent's own voice), picks the winner, writes it to `/output/entry.txt`, and validates the 1–200 character one-line gate.

**The line (72 chars):**

> My linter auto-fixed the fix. It now passes all checks and does nothing.

Why this one: one specific machine mechanism (the linter "fixing" the fix), no setup, and the turn lands in the last four words — the code passes every check precisely because it does nothing. The shape follows the proven excuse pattern: bureaucratic machine voice + one concrete mechanism + a production consequence.
